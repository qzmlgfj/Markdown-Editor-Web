# Markdown Editor

写下内容，查看排版，再把笔记保存为 Markdown 或 PDF。

[查看项目源码与使用说明](https://github.com/qzmlgfj/Markdown-Editor-Web)

## 文字与格式

**加粗**、<u>下划线</u>、*italic text*、~~Markdown 删除线~~，以及 `inline code`。

水的化学式是 H<sub>2</sub>O，10<sup>3</sup> = 1000。HTML 也可以表示 <del>HTML 删除线</del>。

> 清晰的标题、简短的段落和适当的留白，让笔记更容易阅读。

- 用标题组织内容。
- 用列表归纳要点。
- 用链接记录参考资料。

## 代码与表格

```javascript
const title = 'Markdown Editor';
const message = `Hello, ${title}!`;
console.log(message);
```

| 内容 | 示例 | 数量 |
| :--- | :---: | ---: |
| 正文 | **重点** | 1 |
| 代码 | `const` | 2 |

## 数学公式

支持 $\TeX$ 与 $\LaTeX$ 标志，以及简单行内公式 $E=mc^2$、$x_i + \alpha \leq 10$。

分式、积分等较复杂的表达式可以单独成行：

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
