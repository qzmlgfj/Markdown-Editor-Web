# Base46 palette sources and notices

`base46.json` contains color tables adapted from [NvChad/base46](https://github.com/NvChad/base46). Each entry records the exact upstream theme URL used for its palette. The application uses the color data; it does not bundle or execute the Neovim plugin.

The upstream repository carries the following MIT notices for its Base46 and Base16 heritage. They are reproduced here with the color data.
