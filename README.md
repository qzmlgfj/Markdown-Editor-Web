# Markdown Editor Web

基于 Vue 3、Naive UI 和 [md-editor-v3](https://imzbf.github.io/md-editor-v3/) 的纯前端 Markdown 编辑器，使用 Vite 构建。

PDF 导出使用 pdfmake 在浏览器内直接生成并预览，支持浅色文档样式及当前 Base46 配色。支持范围和限制见下文；字体来源与许可见 [字体说明](public/fonts/LICENSES.md)。

## 本地运行

建议使用 Node.js 24 LTS（仓库提供 `.nvmrc`），也支持 Node.js 22.13+。

```sh
npm ci
npm run dev
```

`npm run serve` 保留为开发服务器的兼容命令。

```sh
npm run lint     # ESLint 检查
npm run test     # Vitest 单元测试
npm run build    # 构建至 dist/
npm run preview  # 本地预览构建产物
```

将 `dist/` 部署到静态网站服务即可。资源使用相对路径，支持部署到子目录。

## 功能与数据流

- `src/components/Editor.vue`：保存当前 Markdown 文本，提供实时编辑、预览、`.md` 下载，以及“预览 PDF”按钮。
- `src/utils/store.js`：Vuex 管理选中的 Base46 配色和中英文字体，并保存在浏览器本地存储中。默认配色使用固定的 Markdown 预览和代码块样式。
- `src/themes/`：保存 Base46 调色板，并向网页预览和 PDF 输出提供同一组语义颜色。目前有六款浅色配色：GitHub Light、One Light、Gruvbox Light、Solarized Light、Catppuccin Latte 和 Rosé Pine Dawn。配色来源及许可见 [Base46 来源说明](src/themes/LICENSES.md)。
- `src/App.vue`：管理默认模式的浅色／深色状态；选中 Base46 时，编辑区和 Markdown 实时预览采用该配色原生的深浅色外观。
- 页头标题悬停显示应用简介；底栏采用紧凑布局。
- 站点图标使用内置 SVG，无需向第三方图床请求。
- `src/utils/pdf/`：PDF 导出实现（编排、Markdown 转换、样式、字体、代码块、公式）。
- 浏览器打印：保留独立的浅色 `MdPreview` 与 `@media print` 样式，供用户自行使用浏览器打印（Ctrl/Cmd + P）。这是一条手动后备路径，界面不提供显式入口，也不与 pdfmake 导出共用样式。

当前没有后端或 Markdown 自动保存；刷新页面会恢复示例内容，请先下载 `.md` 保存。配色和字体选择会保留。图片上传未配置服务端处理。编辑器的公式、图表、代码高亮等扩展默认依赖外部 CDN，使用这些功能需要网络连接。

## PDF 导出

默认配色导出中性的浅色 PDF；Base46 配色会覆盖网页预览与 PDF 的标题、正文、链接、代码块和背景颜色。深色 Base46 配色下，可在“PDF 样式”勾选“保持深色”；不勾选时使用默认 PDF。浅色 Base46 配色会直接用于浅色 PDF，此时勾选框不可用。鼠标悬停在勾选框上可查看说明。点击“预览 PDF”时，当前 Markdown、PDF 配色和字体会一起保存为本次快照；PDF 在新标签页的浏览器查看器中打开，可使用查看器的下载按钮或 Ctrl+S（macOS 为 Cmd+S）保存。浏览器需允许本站打开新标签页，且启用内置 PDF 查看器。导出不读取网页预览 DOM、滚动位置或折叠状态；PDF 为 A4、无页眉页脚。标注了受支持语言的代码围栏会在 PDF 中语法高亮，Base46 使用对应的 `base_16` 颜色；未标注或未识别的语言按纯文本输出。

支持范围：

- 标题、段落、粗体、斜体、删除线、行内代码、链接、分隔线。
- 无属性的简单 HTML 标签：`<u>`、`<sup>`、`<sub>`、`<br>`、`<strong>` / `<b>`、`<em>` / `<i>`、`<del>` / `<s>`，支持段落内嵌套以及表格、列表中的使用。
- 有序／无序列表及常见嵌套、引用；列表内可包含标题、表格、公式等块。
- Markdown 表格（表头、对齐、跨页重复表头）。
- 图床 URL 图片：完整 HTTP(S) 链接的 PNG/JPEG，导出时加载并嵌入 PDF；支持段落、标题、列表、引用和表格中的图片，按容器宽度及单页高度等比缩小。
- 代码块：按已识别的围栏语言语法高亮，保留真实文本、等宽字体、行号、缩进与空行；允许自然跨页，超长行自动换行且不重复逻辑行号。
- 独立公式 `$$ ... $$`：由 MathJax 生成为自包含矢量 SVG。代码块内的 `$` / `$$` 按代码输出，不会被当作公式。

字体与加载：

- 编辑区上方可分别选择中文字体（思源黑体、思源宋体）、英文字体（Noto Sans、Noto Serif、Lato）和代码字体。代码字体默认 JetBrains Mono，也可独立选择内置英文字体或本机字体；所选字体覆盖代码中的中文字符时，PDF 代码块也用该字体，否则中文回退到正文字体。选项同步作用于 Markdown 预览、浏览器打印和直接导出的 PDF；内置字体选择保存在本机浏览器中。数学公式字体不受这些选项影响。
- 三个字体下拉菜单以分割线区分内置字体和本地字体，底部的“添加本地字体”支持选择系统已安装字体（浏览器支持 [Local Font Access API](https://developer.mozilla.org/en-US/docs/Web/API/Window/queryLocalFonts) 时需由用户授权），也可选择本机静态 TTF/OTF 文件。英文正文和代码块共用本次会话导入的字体池，可以从任一入口导入，再分别选择不同字体；中文字体单独管理。字体数据只在当前页面会话中使用，不上传服务器；刷新后恢复之前选中的内置字体。系统字体访问不受支持或被拒绝时仍可选择字体文件。
- 本机字体须由用户确认嵌入许可。中文可分别提供 Regular/Bold，英文可分别提供 Regular/Bold/Italic/Bold Italic；缺少字面时复用已有字面，外观会受限。单个字面限 50 MB，一次导入总计限 120 MB；部分中文字体在浏览器的系统字体列表中使用英文名称，可改用 TTF/OTF 文件导入。暂不支持 TTC、可变字体、彩色 Emoji 或 WOFF/WOFF2 PDF 嵌入。
- 所有内置字体均采用 SIL OFL 1.1；来源与许可见 `public/fonts/LICENSES.md`。
- 内置字体的网页预览使用 WOFF2，完整 TTF/OTF 仅在首次导出时按需加载并由浏览器缓存；纯拉丁文档不加载中文字体，无加粗/斜体内容不加载对应字面，无代码不加载等宽字体。
- 导出前会检查每个字符实际使用的字体；缺字会列出字符和行号，确认继续预览时以 `?` 占位，不会静默丢失。
- 生成的 PDF 只嵌入实际用到的字形子集。

已知限制：

- 简单行内公式 `$...$` 支持普通表达式、上下标、常见希腊字母和运算符，使用 KaTeX 数学字体区分变量斜体与数字、运算符正体；`\TeX` / `\LaTeX` 使用衬线标志字形，保留错位和紧凑间距，仍可复制为文字。分式、根式、矩阵等复杂命令保留源码，并在预览前弹窗提示，可返回编辑或继续预览。
- 图片仅支持完整 HTTP(S) URL 的 PNG/JPEG，不支持本地／相对路径、Base64 输入、GIF、WebP 或 SVG。通过图片链接入口或 `![描述](https://...)` 插入；没有接入图片上传服务。
- 图床需允许 CORS 跨域读取，不携带登录凭据；网页预览能显示不代表 PDF 能读取。请求失败、跨域受限、无效图片或单张加载超过 15 秒时，按源文行号提示并以 `[图片：alt]` 占位，可返回编辑或继续预览。超过 4000 万像素的图片也会降级。
- PDF 中图片独立成块，文字中夹着的图片会拆成前文、图片、后文；保持原始比例，不放大小图，不自动把相邻段落识别为图注。图片数据随 PDF 保存，下载 Markdown 则仍只保存 URL。
- Mermaid、任意 HTML/CSS 暂不渲染。未支持、带属性或未正确闭合的 HTML 标签保留源码并按行号提示，Mermaid 围栏按普通代码输出。HTML 样式标签须在同一 Markdown 段落或单元格内配对。
- 缺字和转换降级问题在预览前集中提示，列出源文行号与原因；取消时关闭预留的新标签页。检查针对 PDF 导出，不在每次网页预览更新时弹窗。
- 代码块与行内代码中的中文使用正文字体渲染（等宽字体不含 CJK），因此中文部分不是等宽外观。
- 中文没有配套斜体字面，仍保持正体；混排文档中的拉丁斜体使用所选英文字体的 Italic / BoldItalic，行内公式使用独立数学字体。
- 导出依赖同源字体资源；首次导出需要网络可用（加载后可缓存复用）。
- 独立公式是矢量图形，不承诺像正文一样被复制或搜索；简单行内公式使用文本排版。
- 独立公式渲染超过 15 秒或 MathJax Worker 异常时会降级并提示；失效 Worker 会被终止，下一次导出自动重新创建，不缓存本次失败结果。

## PDF 导出输入样例

- `examples/default.md`：编辑器初始内容，展示已支持的文字格式、HTML 标签、代码、表格与公式，链接指向本项目 GitHub 仓库。

- `examples/pdf-export.md`：PDF 导出开发与回归验证的 Markdown 输入，包含中文正文、列表、引用、表格、93 行代码和独立公式。

回归关注点：代码逐行完整且顺序正确、跨页后的正文存在、中文字体、公式清晰度、无页眉页脚；Web 预览与打印路径应继续独立工作。

## 依赖升级（2026-09）

- Vue CLI 4 / Webpack 4 / Babel 构建链迁移至 Vite 8 + Vue 插件 6。
- Vue 升级至 3.5，Vuex 升级至 4.1；保留现有状态管理方式。
- md-editor-v3 从 2.x 升级至 6.5，适配具名导入及打印预览。
- Naive UI 升级至 2.45，图标库升级至 0.13。
- ESLint 升级至 10，使用 flat config；移除旧 Babel ESLint parser 和 core-js。
- `vfonts` 保持 0.0.3（本次核对时的最新版本）。实际安装版本以 `package-lock.json` 为准。

## PDF 导出依赖

- `pdfmake`：浏览器内 PDF 引擎，按需动态加载。
- `markdown-it`：Markdown 解析（与 md-editor-v3 同主版本）。
- `highlight.js`：按代码围栏标注的语言生成 PDF 语法高亮。
- `mathjax-full`：独立公式转自包含 SVG，运行在 Web Worker 中。
- `fontkit`：读取字体 cmap 用于导出前的缺字检查。
- `vitest`：PDF 转换逻辑的单元测试。

新增 HTML、数学字体和 TeX 标志经过真实 PDF 渲染检查。

内置文档字体原始文件约 48.2 MB，新增网页 WOFF2 副本约 32.4 MB；网页只请求当前选中的 WOFF2 字面，PDF 导出按文档内容加载所需原始字面并由浏览器缓存。字体副本可用 `python scripts/build-web-fonts.py` 从原文件重建（需要 fonttools 和 Brotli Python 包）。首屏不主动加载 PDF 引擎。系统字体选择依赖浏览器支持及授权；Safari、其他平台和线上限速环境尚未实测。生产构建仍有大 chunk 提示。
